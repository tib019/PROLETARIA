# Cybersyn 2.0 — Steuerelement

Cybersyn 2.0 ist ein akademisches Forschungsprojekt und eigenständiges Repository.
Es wird **nicht verändert** und dient PROLETARIA als konzeptuelles Steuerelement.

**Repo:** https://github.com/tib019/cybersyn2-hamburg

## Konzeptuelle Integration

Der **Algedonische Kanal** aus Cybersyn (Stafford Beer, 1972) ist das
Vorbild für `opsec/algedonic.py` in PROLETARIA:

| Cybersyn | PROLETARIA |
|----------|------------|
| Algedonischer Kanal | `OpsecAlgedonicChannel` |
| Bedrohungsschwelle → Notfallprotokoll | OPSEC Score → Gegenmaßnahmen |
| Systemische Resilienz | Organisationale Resilienz |
| Dezentrale Koordination | Dezentrale Sicherheitsinfrastruktur |

Das Viable System Model (VSM) ist das konzeptuelle Fundament für dezentrale,
resiliente Organisation — sowohl in der Energieversorgung (Cybersyn)
als auch in der Organisationssicherheit (PROLETARIA).
